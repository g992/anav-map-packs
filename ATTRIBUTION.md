# Data attribution

The repository's MIT license covers automation code only.

Map packs are extracted without modifying tile contents from [OpenFreeMap](https://openfreemap.org/). OpenFreeMap requires attribution to [OpenMapTiles](https://openmaptiles.org/) and [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). OpenStreetMap data is available under ODbL 1.0.

Administrative boundary polygons come from the pinned `gbOpen` section of [geoBoundaries](https://www.geoboundaries.org/). Licenses vary by country and are recorded by the upstream API and repository. The configured snapshot includes ODbL, CC BY, CC BY-SA and public-domain sources. When redistributing a boundary-derived catalog, preserve the applicable upstream attribution.
